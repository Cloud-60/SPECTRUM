Ideate: Brainstorming Solutions

Core Features

  • Smart Bin Tracking: Real-time data on bin fill levels
  • Collection Alerts: Notifications for upcoming waste collections
  • Recycling Tips: Guides for sorting waste
  • Rewards Program: Points system for responsible waste habits

User Flow Diagram

Resident scans QR code on bin → Receives reward points → Schedules reminders.

Municipality Worker views real-time bin data → Optimizes route for collection.

Key Functions and Flow

  • Real-Time Bin Data: Municipality and residents can monitor fill levels

Test: Gathering Feedback

Usability Testing Plan

Methods used: User Interviews with residents and municipality workers, and short surveys for usability feedback.

Feedback Summary

"The map is very useful to locate the nearest bin!"

"I’d like clearer instructions for QR code scanning."

Iterations Based on Feedback

  • Enhanced Navigation: Easier access to eco-tips and rewards
  • More Visual Cues: Color-coded bins for easy status checking
